👥 Bóveda Local de Contraseñas de Contribuyentes

Las claves del SRI de los clientes viven de manera aislada en este navegador (sc_clients_cache). Puedes cargarlas masivamente desde la exportación de contraseñas de Chrome o desde un archivo CSV simple (RUC,Clave).

🔒 Por qué acá y no en el código

    
    
        
  1. shared_config.js está en el repositorio: lo que se escribe ahí
            queda en el historial de git para siempre, aunque después se borre.
    2. 
        
  2. Ese archivo además viaja dentro de la extensión y se inyecta en cada página
            del SRI.
    3. 
        
  3. Esto, en cambio, vive en chrome.storage.local:
            solo en esta computadora, sin versionar y sin distribuir.
    4. 
        
  4. Del lado de Google conviene además restringir la clave a la API que
            usás y ponerle cuota diaria: si algún día se escapa, el daño tiene techo.
    5.
