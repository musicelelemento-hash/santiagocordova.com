Con una cédula ajena no se baja la declaración de nadie

Hasta el 07-sep-2026 el comprobante de cada contribuyente vivía en declaraciones/<RUC>/Declaracion_IVA_<RUC>_<periodo>.pdf, servido por el dominio público pub-*.r2.dev. El RUC en Ecuador es la cédula + 001, así que la ruta se deducía de un dato público: con el número de cédula de alguien se le bajaba la declaración.

Cuando el link viaja por WhatsApp, el link ES la credencial. Lo que no puede pasar es que la credencial se derive de algo que cualquiera sabe.
